# PRIMAL CROWN

Thailand-first The Isle EVRIMA community platform.

This repository is being initialized for the **Alpha 0.1 Foundation**. The live game server, public website, Discord app, and paid membership systems are **not deployed**.

The purpose of the project is a fair-play community built around party finding, persistent herds, events, moderation and operational reliability. Official game binaries, credentials and unapproved game modifications must not be committed.

See upcoming project foundation pull request for setup and development instructions.
